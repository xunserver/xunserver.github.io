密码人生 ​

这是一份可公开分发的密码数据。外层使用 Base64 文本封装，仓库中只保存一个普通的 data.dat 数据文件。首次创建时生成一把随机 DEK，并由多个家人密钥分别包裹；以后每次更新正文都复用原 DEK 和原全部密钥槽，只重新生成正文的 AES-GCM IV 与密文。

因此，只要没有主动做密钥轮换，第一次发给家人的恢复密钥可以长期保持有效。

所有加解密都在浏览器本地完成。将生成的 Base64 数据保存到 public/assets/data.dat 并提交；GitHub Actions 只负责构建和发布密文，不需要任何解密密钥。

离线恢复建议长期保存 recovery.html + RECOVERY.txt；它们不依赖博客和 GitHub Pages。

密码恢复指南 ​

即使本网站以后无法访问，也可以从多个公开分发渠道取回同一份加密备份。无论使用哪种方式，最终都需要这三样东西：

  1. data.dat：加密后的密码内容。
  2. recovery.html：可以离线打开的解密网页。
  3. 任意一把仍然有效的恢复密钥（例如 EV2-XXXX-XXXX-...，请向持有人单独索取）。

安全提示： 下载渠道只提供加密文件，不包含恢复密钥。不要把恢复密钥输入到不可信的网站，也不要把它发布到 GitHub、npm 或 Docker Hub。下载完成以后可以断网，直接在本机解密。

方式一：直接下载离线恢复文件 ​

这是最简单的方式，不需要安装 npm 或 Docker。

  • 下载离线解密网页 recovery.html
  • 下载加密文件 data.dat
  • 查看恢复使用说明 RECOVERY.txt

把下载的 recovery.html 和 data.dat 放在同一个文件夹。然后按照下方的「实际解密步骤」恢复密码。

方式二：GitHub Releases（完整 ZIP 备份） ​

如果网站或域名失效，可以到 GitHub 公开恢复包发布页 下载 password-life-recovery.zip。

  • 解压 ZIP，进入 password-life-recovery 文件夹。
  • 找到 recovery.html、data.dat 和 RECOVERY.txt。
  • ZIP 内有 SHA256SUMS，Linux 可在该文件夹执行 sha256sum -c SHA256SUMS，macOS 使用 shasum -a 256 -c SHA256SUMS 检查文件完整性。
  • 打开 recovery.html，按下方步骤解锁。

方式三：npm Registry（公共 npm 包） ​

npm 包名：@xunserver/password-life-recovery。

电脑安装了 Node.js / npm 后，进入一个空目录。Linux、macOS 或使用 Bash 的 Windows 用户执行：

bash
# 下载公开 npm 包，不运行其中的程序
archive=$(npm pack @xunserver/password-life-recovery --silent)

# 解压为 ./package/ 目录
tar -xzf "$archive"

# 查看恢复文件
ls package

方式四：Docker Hub（公共 OCI 镜像） ​

Docker 镜像是一个只读文件归档，不是需要启动的密码服务。镜像内部的恢复文件放在 /recovery/ 目录下。

先在 Docker Hub 搜索 password-life-recovery，确认对应的公开镜像及发布者。下面的 DOCKERHUB_USERNAME 必须替换成镜像的实际发布用户名，不是字面复制。

Linux/macOS Bash：

bash
IMAGE="DOCKERHUB_USERNAME/password-life-recovery:latest"

# 下载镜像
docker pull "$IMAGE"

# 创建但不运行容器，只用来取文件
cid=$(docker create "$IMAGE" /bin/true)
mkdir -p recovery
docker cp "$cid:/recovery/." ./recovery/
docker rm "$cid"

# 校验提取的文件
cd recovery
sha256sum -c SHA256SUMS  # macOS 请改为：shasum -a 256 -c SHA256SUMS

/bin/true 只是 docker create 的占位命令，不会被执行。镜像基于 scratch，无需启动容器。

下一步： 从提取的 recovery 文件夹打开 recovery.html，选择同一文件夹的 data.dat，使用恢复密钥解锁。文件取出以后不再需要 Docker。

如果希望固定一个历史版本，可使用 Docker Hub 上的版本标签（例如 sha-5d4b4ec15cff）或镜像 digest，而不是 latest。

实际解密步骤（以上所有方式通用） ​

  1. 把 recovery.html 和 data.dat 保存到本机。
  2. 双击 recovery.html，使用 Chrome、Edge、Firefox 或 Safari 打开。此页面不需要联网。
  3. 点击页面上的「选择 data.dat」，载入下载的密文。
  4. 输入任意一个有效的恢复密钥，点击「解锁」。
  5. 解密后的明文仅在当前浏览器中显示，可以自行复制并妥善保存。

如果你还有正在运行的“密码人生”页面，也可以在页面上方的「再次编辑」中导入密文并解锁；长期归档仍建议同时保存独立的 recovery.html，以免网站失效。

目前的命令行恢复能力

上述 npm 和 Docker 发布物目前主要提供 recovery.html、data.dat 和使用说明，尚未提供已经发布并验证的 decrypt.sh / decrypt.mjs / decrypt.py 解密脚本。因此无浏览器的 Linux 服务器不能仅靠 npm pack 或 docker pull 完成解密。未来加入命令行解密器后会同步更新这些公开渠道。

建议的长期保存方式 ​

至少保留一份最新的 ZIP / npm 包 / Docker 镜像中提取的恢复文件，并把恢复密钥单独交给可信任的家人。不同平台上的版本可能更新时间不同；解密前优先选择较新的 data.dat，不要用过期备份覆盖新文件。对于长期归档，最好同时保存文件校验值和对应版本号。
