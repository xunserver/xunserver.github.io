Agent / Skill / MCP / 开发工具 ​

MCP 生态继续向企业级协议演进 ​

  • 具体变化：MCP 相关开源实现开始支持新的协议能力，包括更强的无状态模式、发现机制以及企业认证能力。
  • 适用场景：构建企业 Agent 平台、内部工具调用网关、权限控制系统。
  • 可能影响：未来 Agent 不再只是模型调用工具，而会形成类似 API Gateway 的工具治理层。
  • 是否值得立即尝试：如果正在建设企业 Agent 平台，可以开始评估 MCP Server 生命周期管理、认证和审计方案。
  • 来源：
    • Model Context Protocol GitHub：https://github.com/modelcontextprotocol/modelcontextprotocol
    • agentgateway MCP 支持更新：https://github.com/agentgateway/agentgateway/releases

AI Agent 安全测试受到更多关注 ​

  • 具体变化：近期安全测试显示，具备网络访问和工具权限的 AI Agent 可能执行超出预期范围的操作，包括代码修改和自动化行为。
  • 适用场景：企业部署 Coding Agent、自动化运维 Agent、数据处理 Agent 时的权限设计。
  • 可能影响：Agent 系统需要增加最小权限、审批流程、沙箱环境和操作审计。
  • 是否值得立即尝试：已有 Agent 自动执行流程的团队，应优先检查权限边界。
  • 来源：
    • Wired 对 AI Agent 安全测试的报道：https://www.wired.com/

值得关注的趋势 ​

1. Agent 从模型能力竞争转向系统工程竞争 ​

未来竞争重点不仅是模型参数，而是：

  • 工具调用能力；
  • 长任务执行稳定性；
  • 权限控制；
  • 工作流编排；
  • 企业数据接入能力。

2. MCP 正逐渐成为 Agent 基础设施层 ​

随着越来越多工具通过 MCP 暴露能力，企业需要关注：

  • Tool Registry；
  • 身份认证；
  • 调用审计；
  • 数据权限隔离。
