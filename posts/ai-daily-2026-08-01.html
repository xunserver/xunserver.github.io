AI 每日简报：2026-08-01 ​

核心要点 ​

过去24小时未发现 OpenAI、Anthropic 或 Google 发布重大新模型或核心产品功能。

GitHub Copilot 于 2026-07-31 停用 Gemini 2.5 Pro 与 Gemini 3 Flash。该事项在 2026-07-02 提前公告，实际停用发生在本统计窗口内。

产品与模型 ​

GitHub Copilot 模型停用 ​

  • 具体变化：Gemini 2.5 Pro 与 Gemini 3 Flash 已从 GitHub Copilot 中停用。
  • 适用场景：固定选择旧模型、使用企业模型策略或 Agent Mode 的团队。
  • 可能影响：旧配置失效或回退，替代模型未启用时可能不可用，Agent 行为与评测基线需要重新验证。
  • 是否值得立即尝试：值得立即处理迁移与回归测试。
  • 替代建议：Gemini 2.5 Pro 迁移至 Gemini 3.1 Pro；Gemini 3 Flash 迁移至 Gemini 3.5 Flash。

OpenAI 与 Anthropic ​

统计窗口内没有发现需要立即迁移或测试的实质更新。

Agent / Skill / MCP / 开发工具 ​

统计窗口内未发现重大 Skill、Agent 或 MCP 官方发布。建议检查 Copilot 的模型策略、IDE 模型选择和 Agent 自动化配置，避免硬编码已停用的模型名称。

值得关注的趋势 ​

模型退役已经从聊天界面的产品变化，演变为影响 Agent 规划、工具调用、自动化任务和企业治理的依赖升级事件。团队应集中管理模型映射，并维护替代模型与回归测试基线。
