Agent / Skill / MCP / 开发工具 ​

GitHub Copilot Billing Preview 应用正式退役 ​

  • 具体变化：GitHub 已于 2026-08-03 退役 Copilot Billing Preview 应用。该应用此前用于查看 Copilot 从固定订阅逐步转向 usage-based billing 后的费用与用量数据。
  • 替代能力：
    • GitHub Billing 设置中的 AI usage 页面；
    • 组织与企业级预算控制；
    • cost center 与 per-user budget；
    • Usage reports；
    • Billing API。
  • 适用场景：使用 GitHub Copilot Business / Enterprise，并需要跟踪 AI credits、个人预算、成本中心或团队用量的组织。
  • 可能影响：依赖 Billing Preview 应用进行成本核算、月度报表或预算检查的流程将失去原入口；若内部脚本或操作手册仍指向该应用，需要同步修改。
  • 是否值得立即尝试：值得立即检查，但不需要专门试用。 应确认团队是否仍保存旧入口、书签或操作文档，并验证内置 Billing 页面与 API 是否能覆盖现有报表需求。

值得关注的趋势 ​

1. AI 开发工具开始进入成本治理阶段 ​

Copilot、Codex、Claude Code 等工具的企业采用重点，正在从“是否可用”转向“如何计量、分配和限制使用”。模型路由、长上下文和 Agent 自动化都会增加用量波动，因此预算、成本中心、per-user limit 和 usage export 会逐渐成为企业级 Agent 平台的标准能力。

2. 产品退役也属于需要跟踪的实质变化 ​

每日 AI 简报不应只记录新模型和新功能。对于已经进入生产流程的工具，入口退役、API 停止、模型下线和计费方式变化，往往比一般功能更新更需要立即处理。

3. 本期不使用旧闻填充 ​

虽然近期 AI 领域仍有大量模型、Agent、Skill 与 MCP 相关动态，但在本次24小时统计窗口内，没有发现其他经过官方渠道确认、且具备足够信息增量的重要发布，因此不重复收录窗口外内容。
